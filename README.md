# JAM Soft — Plataforma de Monitorizacao

Dashboard central para monitorizar as farmacias da rede JAM Soft.

## Funcionalidades

- Ver todas as farmacias activas
- Vendas de hoje por farmacia
- Ticket medio
- Formas de pagamento
- Evolucao ultimos 7 dias

## Tecnologia

- Streamlit (dashboard)
- Supabase (base de dados na nuvem)
- Python 3.12
